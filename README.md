# موقع الجمعية المصرية لدرء المخاطر

موقع كامل (واجهة + لوحة تحكم) مبني بـ Next.js 16 + Prisma + SQLite.

## التشغيل محليًا

```bash
npm install
npx prisma db push      # إنشاء قاعدة البيانات (أول مرة فقط)
npm run db:seed         # تعبئة البيانات الأولية (أول مرة فقط)
npm run dev             # تشغيل الموقع على http://localhost:3000
```

## لوحة التحكم

- الرابط: `http://localhost:3000/admin`
- البريد الإلكتروني: `admin@erms.org.eg`
- كلمة المرور الافتراضية: `Erms@3880`

**مهم:** غيّر كلمة المرور فورًا من: لوحة التحكم ← إعدادات الموقع ← تغيير كلمة المرور.

من لوحة التحكم يمكن إدارة: الأخبار، المؤتمرات، الدورات التدريبية، البرامج الدراسية
(ماجستير/دكتوراه) ومقرراتها، أعداد المجلة (مع رفع PDF)، أعضاء مجلس الإدارة، اللجان،
رسائل التواصل، وكل نصوص الموقع من صفحة الإعدادات.

## بنية المشروع

- `app/(site)/` — صفحات الزوار (الرئيسية، من نحن، المؤتمرات، الأخبار، المجلة، التدريب، البرامج، اتصل بنا)
- `app/admin/` — لوحة التحكم (محمية بتسجيل دخول)
- `prisma/schema.prisma` — نماذج قاعدة البيانات
- `prisma/seed.ts` — البيانات الأولية
- `public/img/` — صور الموقع الأساسية
- `public/uploads/` — الملفات المرفوعة من لوحة التحكم

## النشر (Production)

```bash
npm run build
npm start
```

- يحتاج استضافة تدعم Node.js (VPS أو خدمة مثل Railway / Render).
- ملاحظة لـ Vercel: نظام الملفات مؤقت هناك، فقاعدة SQLite ورفع الملفات لن يعملا —
  يلزم التحويل إلى Postgres (تغيير سطر واحد في `schema.prisma`) وتخزين خارجي للملفات.
- غيّر `AUTH_SECRET` في ملف `.env` إلى قيمة عشوائية طويلة قبل النشر.
